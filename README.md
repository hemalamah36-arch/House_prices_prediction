# House Price Prediction

## Project Overview

This project predicts house prices using a Linear Regression machine learning model.

## Dataset

The dataset contains information about houses, including:

* Area
* Bedrooms
* Bathrooms
* Age
* Location Score
* Price

## Machine Learning Model

The project uses **Linear Regression** from Scikit-learn.

## Steps

1. Load the house price dataset using Pandas.
2. Explore the data.
3. Select features and target variable.
4. Split the data into training and testing sets.
5. Train a Linear Regression model.
6. Make predictions.
7. Evaluate the model using:

   * MAE
   * MSE
   * RMSE
   * R² Score
8. Visualize actual vs. predicted prices.

## Files

* `house_prices1.ipynb` — Jupyter Notebook containing the complete project.
* `house_prices.csv` — Dataset used for the project.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
